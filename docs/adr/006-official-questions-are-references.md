# ADR-006: Official past questions are references, not repository content

- **Status:** Accepted
- **Date:** 2026-08-16

## Context

共通テスト等の公式問題の二次利用は大学入試センターの申請手続きと第三者権利の処理を必要とする。

## Decision

公式問題の PDF・OCR・問題文・図・会話文・選択肢のコピーをリポジトリに置かない(一時的にも不可)。許可されるのはリンク・メタデータ・Maintainer が独自に作成した構造分析・学習目標タグ・独立したブリーフから作成した独自問題・適法な短い引用のみ。

## Consequences

- 共通テスト「風」教材は独自の非公式演習教材である旨を必ず表示する。
- 公式コンテンツの再利用が必要な場合は、センターの申請手続きと第三者権利の処理を個別に行う。
