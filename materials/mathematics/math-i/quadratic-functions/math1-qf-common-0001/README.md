# math1-qf-common-0001 — 二次関数の最大・最小(演習)

数学I「二次関数」単元の共通テスト風(独自)演習教材。フェンスで囲む花壇の面積を題材に、立式 → 頂点 → 定義域制限下の最大・最小 → 選択肢問題の流れで構成する。

**本教材は共通テストの出題形式を参考にした独自の演習教材であり、過去問題や公式サンプル問題ではありません。**

## ビルド

```bash
cd python && uv run manabi tex build \
  ../materials/mathematics/math-i/quadratic-functions/math1-qf-common-0001
```
