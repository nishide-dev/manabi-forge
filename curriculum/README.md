# Curriculum knowledge base

公式資料に基づく機械可読なカリキュラムデータ(spec §10)。

| ディレクトリ | 内容 |
|---|---|
| `sources/` | ソースマニフェスト(URL・取得日・チェックサム・メディアタイプ)。**再配布が許可されないファイル本体は置かない** |
| `normalized/` | 正規化されたカリキュラムレコード(YAML) |
| `annotations/` | Maintainer による解釈・クロスウォーク注釈 |
| `snapshots/` | バージョン付きスナップショットと差分 |

ソース階層: 法令・官報告示 > 学習指導要領解説 > 教育課程コード表(84V10)> 試験実施方針・評価報告 > 教科書目録・編修趣意書 > 公的データセット > Maintainer 注釈。OCR 出力は人間の照合なしに正とみなさない。
