# TeX templates

LuaLaTeX 教材テンプレート(spec §15)。テンプレートは視覚構造のみを所有し、教科の内容は教材ソースが所有する。セマンティックバージョンを持ち、成果物はテンプレート ID とバージョンを記録する。

| ディレクトリ | 用途 |
|---|---|
| `common-test/` | 共通テスト風演習教材(独自デザイン・非公式表示必須) |
| `guided-example/` | 段階解説型(concept → worked example → strategy → solution → notes → practice) |
| `worksheet/` | 授業プリント向けレイアウト |
| `answer-sheet/` | 解答用紙 |
| `shared/` | プロジェクト共有の `.cls` / `.sty` |

商用シリーズの誌面デザインを模倣しない。shell escape は使用禁止。
